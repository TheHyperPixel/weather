# app

A basic starter app project for Firebase.

## Getting Started

To use this - copy the following files or folders into your new project:

1. ios/Podfile
2. macos/Podfile
3. lib (folder)
4. analysis_options.yaml
5. pubspec.yaml
6. injector.dart

Then - initialise Firebase and register the app

## Injectable: 

flutter pub run build_runner build --delete-conflicting-outputs
